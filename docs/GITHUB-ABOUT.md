# GitHub "About" panel — copy and paste

GitHub's **About** panel is repository metadata, not a file, so it has to be set in the UI:
open the repository → click the ⚙️ gear beside **About** (top right) → paste the fields below.

---

## Description

GitHub allows 350 characters. Use the version that fits where you are sending the link.

**Recommended (fits comfortably, reads well in search results and on a CV):**

```
Production church finance, governance and fundraising platform for RCCG Kingdom Parish, Aguleri — automated RCCG remittance calculation, cash and petty-cash control, an AI meeting secretary for a 12-member stewardship committee, and a public partnership programme. Cloudflare Pages + D1, vanilla JS PWAs, 481 tests.
```

**Short (if you want it to fit on one line on mobile):**

```
Church finance, governance and fundraising platform — automated RCCG remittance engine, cash control, AI meeting secretary and partnership fundraising. Cloudflare Pages + D1, vanilla JS PWAs.
```

**Analyst-forward (if the link is going on a CV or a job application):**

```
End-to-end business analysis, process redesign and delivery of a 3-app platform running a parish's finances, governance and fundraising: 26-line remittance engine, 40-table data model, 12 roles, 9 automations, 481 tests.
```

## Checkboxes

- ☑ **Releases** — off (no releases published)
- ☑ **Packages** — off
- ☑ **Deployments** — on (Cloudflare Pages deployments show delivery cadence, which is worth
  showing to an employer)

## Pinning it

If this is going on a CV, pin the repository on your GitHub profile:
profile → **Customize your pins** → select this repository. Pinned repositories are the first
thing a recruiter sees, and the README's screenshots section does the rest of the work.

---

## Authorship statement

The About panel caps at 350 characters, so the full statement lives at the bottom of the
README under **Authorship and method** — that is where anyone who reads the About box will
land next. Keep it there.

If you want the About box itself to carry the signal, use this variant of the description
(328 characters):

```
Production church finance, governance and fundraising platform for RCCG Kingdom Parish, Aguleri — automated RCCG remittance engine, cash control, AI meeting secretary and partnership fundraising. Original analysis, financial rules and product design; built with AI pair-programming assistance across 290 reviewed PRs. 481 tests.
```

Use the same sentence in your LinkedIn project entry and on the CV — see
`docs/PORTFOLIO.md` §0 for the wording and for how to handle it at interview.

## Social preview image

Settings → General → **Social preview** → upload an image. `docs/screenshots/02-finance-dashboard.png`
works well — it shows a real, populated product rather than a logo, which is what makes a
shared link stop a recruiter mid-scroll. GitHub recommends 1280×640px.
