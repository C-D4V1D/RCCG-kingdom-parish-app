# Privacy policy

This project is a private parish administration tool used by a small admin team. It is not offered to the public.

- The box backup tool ("Clerk Box rclone") only accesses the owner's own Google Drive, to back up the parish automation files to a folder the owner controls.
- No data is sold, shared with third parties, or used for advertising.
- Personal data handled by the parish app is limited to what the parish admin team needs for church administration, and is kept only for that purpose.
- Questions: open an issue in this repository.
